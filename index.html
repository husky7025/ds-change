1. 결보강 탐색기란?

선생님이 출장·연가·병가 등으로 수업을 비우게 되었을 때, 누가 그 수업을 대신 맡거나 맞바꿀 수 있는지 자동으로 찾아주는 도구입니다.

  • 시간표를 일일이 대조하지 않아도 됩니다.
  • 공강인 선생님, 같은 과목 선생님을 우선으로 찾아줍니다.
  • 찾은 결과를 바로 결보강 계획서(HWPX/PDF)로 출력할 수 있습니다.
💡 용어 정리 (처음 보시는 분께)
단어뜻
결강선생님이 자리를 비워서 원래 수업이 열리지 않는 것
보강비는 수업을 다른 선생님이 대신 맡아 들어가는 것
교체 (맞교환)두 선생님이 서로의 수업 시간을 맞바꾸어 진행하는 것 (학교 권장 1순위)
공강선생님이 수업이 배정되지 않은 빈 시간
시간표 파일전교사의 시간표가 들어 있는 기본 데이터 (timetable.csv)

2. 처음 열면: 시간표 불러오기

탐색기를 열면 시간표가 자동으로 불러와집니다. 화면 상단의 상태 배너에 "✅ 시간표 데이터 준비 완료"가 나타나는지 확인하세요.

  • 시간표가 확인되면 바로 탐색을 시작할 수 있습니다.
  • 시간표가 비어 있거나 "불러오기 실패"가 뜨면, 상단의 🔄 시트 동기화를 눌러 다시 불러오세요. 그래도 안 되면 인터넷 연결을 확인하세요.
💡 이 도구는 인터넷 외부 서버 없이, 선생님의 브라우저 화면 안에서만 안전하게 동작합니다. 개인정보나 학교 시간표가 외부로 절대 전송되지 않습니다.

3. 화면 구성

화면은 크게 두 가지 모드로 나뉩니다. 상단 탭을 눌러 언제든 자유롭게 전환할 수 있습니다.

모드언제 쓰나요?
🔍 단일 차시 탐색하루 중 한두 시간만 비울 때 (예: 오늘 2~3교시만 출장 또는 연가)
✈️ 출장·연가 패키지 모드며칠씩 자리를 비울 때 (예: 3일 출장, 일주일 연가로 여러 수업 일괄 처리)

그 밖에 자주 쓰는 유용한 버튼들입니다.

버튼기능 설명
📊 내 시간표특정 선생님의 일주일(월~금 1~7교시) 시간표를 한눈에 조회합니다.
🔍 변동 시간표 시뮬레이션교체·보강을 적용했을 때 시간표가 어떻게 바뀌는지 전후를 미리 비교합니다.
📋 메신저 복사결과를 교내 메신저나 카카오톡 단톡방에 붙여넣기 좋게 깔끔한 텍스트로 복사합니다.
🖨️ 계획서 인쇄(PDF)대전동산고 공문 서식에 맞추어 바로 인쇄하거나 PDF로 저장합니다.
📥 HWPX 다운로드한글(HWPX) 원본 파일로 내려받아 세부 내용을 다듬거나 전자결재에 첨부합니다.

4. 단일 차시 탐색하기 (한두 시간만 비울 때)

1단계 기준 교사명을 입력합니다
자리를 비우는 선생님의 이름을 입력합니다. (예: 권상명)
2단계 결강 사유를 선택합니다
출장 / 연가 / 병가 / 공가 / 특별휴가 / 기타 중에서 선택합니다.
3단계 결강 날짜와 교시를 정합니다
1. 결강/교체 일자 달력에서 날짜를 고르면 요일이 자동으로 연동됩니다.
2. 결강/교체 교시에서 비는 교시(1~7교시)를 누릅니다. (여러 교시 다중 선택 가능)
4단계 탐색 옵션 설정 (선택 사항)
- 특정 보강 교사: "이 선생님께 부탁드리고 싶다"는 분이 있으면 이름을 직접 지정할 수 있습니다.
- 연속수업 방지: 앞뒤로 수업이 연달아 붙어 피로도가 가중되는 것을 방지합니다.
5단계 결과 확인 및 최적 후보 선택
후보는 1) 동일 교과군 우선 → 2) 이름 가나다순으로 정렬됩니다. 후보에는 그 시간에 수업이 없는 교사만 나옵니다.
6단계 계획서 출력
🖨️ 계획서 인쇄(PDF) 또는 📥 HWPX 다운로드 버튼을 눌러 양식을 출력합니다.

5. 출장·연가 패키지 모드 (며칠씩 비울 때)

2~3일 출장이나 일주일 연가처럼 기간 내 여러 차시 수업을 한 번에 일괄 처리할 때 사용합니다.

1단계 출장 정보 입력
출장 교사명 입력 후, 달력에서 시작일과 종료일을 선택합니다.
2단계 출장 수업 일괄 추출
[출장 수업 불러오기] 버튼을 누르면 해당 기간 내 모든 수업 목록이 표로 정렬되어 나타납니다.
3단계 원클릭 최적 자동 배정 (교체 1순위)
[원클릭 최적 자동 배정]을 누르면 시스템이 스스로 다음 원칙에 따라 최적 매칭합니다:
  • 수업 교체(1:1 맞교환) 1순위: 파트너가 희소한 차시부터 우선 매칭하여 성립률 100% 극대화
  • 교체 불가 차시만 보강(2순위)으로 자동 전환
  • 동일 학급 수업은 가능한 같은 선생님이 맡도록 연속성 보장
  • 교사별 일일/누적 보강 부하 자동 분산
4단계 1장 일괄 출력
드롭다운에서 마음에 드는 후보로 언제든 변경할 수 있으며, [출장 계획서 HWPX 일괄 다운로드]를 누르면 1장의 결재 대장으로 즉시 생성됩니다.

6. 결과 표 보는 방법

표시뜻과 추천 기준
🔄 [교체]서로 수업을 1:1로 맞바꾸는 형태 (학교 행정 권장 1순위)
📋 [보강]상대 교사가 빈 시간에 대신 들어가는 형태 (2순위)
동일 교과결강 과목과 같은 과목군 선생님 (수업 연속성 최고)
연속수업 주의앞뒤 시간에 이미 수업이 있어 2~3시간 연속 수업이 되는 경우
누적 배정이번 출장 기간 동안 해당 선생님에게 배정된 총 차시 수

7. 내 시간표 보기

특정 선생님의 주간 시간표가 궁금할 때 상단의 [📊 내 시간표] 버튼을 누르고 교사명을 입력하면 월~금 1~7교시 시간표를 한눈에 확인할 수 있습니다.

8. 변동 시간표 시뮬레이션 비교

"이렇게 교체하면 시간표가 어떻게 바뀔까?"를 확정하기 전에 미리 검증하는 기능입니다.

  • 후보를 선택한 후 [🔍 변동 시간표 시뮬레이션 비교]를 누릅니다.
  • 변경 전 시간표와 변경 후 시간표가 나란히 비교되어 충돌 여부를 한눈에 점검할 수 있습니다.
  • 화면 상의 가상 시뮬레이션이므로 실제 원본 데이터가 바뀌지 않으니 안심하고 테스트하세요.

9. 시간표 수정하기 (새 학기/시간표 변동 시)

시간표는 구글 스프레드시트에서 실시간으로 불러옵니다. 파일을 올릴 필요가 없습니다.

  1. 상단의 [📊 시간표 시트 열기]를 누릅니다.
  2. 구글 시트에서 시간표를 수정하거나 새 시간표를 붙여넣습니다.
  3. 탐색기로 돌아와 [🔄 시트 동기화]를 누르면 바로 적용됩니다.
⚠️ 주의할 점
• 학급명은 반드시 2-1, 3-9처럼 "학년-반" 형태로 기재해야 합니다.
• 엑셀에서 3-9가 날짜(3월 9일)로 자동 변환되는 것을 방지하기 위해 텍스트 서식으로 입력하세요. (시스템 내 자동 복원 기능도 내장되어 있습니다.)

10. 자주 묻는 질문 (FAQ)

Q. 교체가 가능한 후보가 보이는데 자동 배정에서 보강으로 배정되었어요. 왜 그런가요?
A. 다른 차시가 해당 교사의 공강 슬롯을 먼저 선점했거나, 출장 교사 본인의 복귀 후 시간표에 충돌이 발생하는 경우입니다. 본 시스템은 희소 교체 우선 알고리즘을 통해 전체 수업 중 교체 성립률을 극대화하도록 최적 배치합니다.
Q. 계획서 인쇄 시 배경 색상이나 표 테두리가 나오지 않아요.
A. 브라우저 인쇄 대화상자에서 [설정 더보기] → [배경 그래픽] 항목에 반드시 체크해 주세요. 여백은 '없음'으로 설정하시면 학교 표준 규격에 완벽히 들어맞습니다.
Q. 한글(HWPX) 파일로 직접 편집하고 싶어요.
A. [📥 HWPX 다운로드] 버튼을 누르시면 대전동산고 표준 19열 서식 및 학교장 명의가 반영된 온전한 .hwpx 파일이 다운로드됩니다. 한컴오피스에서 열어 결재를 올리시면 됩니다.
Q. 데이터가 외부 인터넷에 유출되지 않나요?
A. 전혀 유출되지 않습니다. 모든 연산과 시간표 검색은 선생님의 PC 브라우저 메모리 안에서만 100% 정적으로 처리됩니다.
